# HSK5 บทที่ 4 — 被删掉的名字

## สมุด PDF สำหรับ iPad

`HSK5_4_workbook.pdf` มี 15 หน้า: ศัพท์ 19 คำพร้อมพินอินและความหมาย เรื่อง 3 ตอนพร้อมภาพ แกรมม่า 3 จุดพร้อมตัวอย่างจุดละ 3 ประโยค พื้นที่เขียน และแบบฝึก 10 ข้อพร้อมเฉลย ดาวน์โหลดได้จากหน้า HTML; สร้างใหม่ด้วย `../build_pdf_workbooks.py` หลังแก้ข้อมูลบท

## ข้อมูลต้นทางและการนับคำ

`สมุดคำศัพท์จีน (3).xlsx` เป็นสมุดสะสมในชีต `คลังคำศัพท์` คอลัมน์ B–D แถว 6–81 บท 1–3 ใช้แถว 6–62 แล้ว บทนี้จึงใช้ **19 รายการใหม่ในแถว 63–81** ตามลำดับต้นฉบับ

รายการเปรียบเทียบใน Excel ถูกแปลงเป็นคำที่กดเรียนได้: แถว 75 `地点VS'地方` ให้คำใหม่ `地方` เพราะ `地点` มีแล้วในแถว 67; แถว 76 `咱们VS我们` ให้คำใหม่ `咱们` และอธิบายเทียบ `我们`; แถว 77 `得（DEI）` ใช้ `得` อ่าน `děi` เมื่อหมายถึง “ต้อง” (ในประโยค `写得很清楚` อ่าน `de`); แถว 80 `无论。。。，也/都` ใช้คำ `无论` และสอนโครงสร้าง `无论……都/也……` ไฟล์ Excel ต้นฉบับไม่ได้ถูกแก้ไข

## ไฟล์

- `HSK5_4.html`: เรื่องต่อ 3 ตอนพร้อมภาพ คำจีนทุกคำใน reading กดดูพินอินและความหมายได้ เปิดปิดพินอินและคำแปลทั้งตอนแยกกัน คลังศัพท์ 19 คำ บัตรคำ และข้อสอบ 10 ข้อ
- `anki_hsk5_4.txt`: 19 บัตรคำ แบบ UTF-8 คั่นด้วย Tab; ฟิลด์ Front / Back / Tags
- `lesson_data.json`: แหล่งข้อมูลคำศัพท์ เรื่องอ่าน พินอิน คำแปล และข้อสอบ
- `build_lesson.py`: สร้าง HTML และ Anki จาก JSON โดยใช้บท 5_3 เป็นแม่แบบ รันจากโฟลเดอร์หลักด้วย `python3 HSK5_4/build_lesson.py`
- `images/`: ภาพสามฉากสีน้ำที่สร้างด้วย built-in imagegen ต่อจากตัวละครเดิม

ไฟล์ร่วมในโฟลเดอร์หลัก `build_shared_data.mjs` รวมคำศัพท์สี่บทเป็น `vocabulary-data.js` และตรวจคำในเรื่องอ่านทุกบทกับ `reading-glossary.json` ก่อนสร้าง `reading-lexicon.js` หากแก้เรื่องหรือเพิ่มคำ ให้รัน `node build_shared_data.mjs` แล้วเพิ่มคำทั่วไปที่ตัวตรวจรายงานจนผ่าน

## ปมต่อไป

ตำรวจพบว่าหลินเสวี่ยเป็นผู้แจ้งเบาะแสคนแรก ไม่ใช่ผู้ใช้ที่ถูกลบ ผู้จัดการลบชื่อเธอเพื่อหลอกบริษัทคู่ค้า แต่ข้อความล่าสุดบอกว่ายังมีผู้รับผิดชอบอีกคนที่ไม่ปรากฏตัว บทถัดไปควรสืบว่าคนนั้นคือใครและเกี่ยวข้องกับหลินอวี่อย่างไร

## ตรวจและเผยแพร่บทใหม่

1. เทียบ Excel ใหม่กับบท 1–4 และระบุแถวคำใหม่หรือแถวเปรียบเทียบ
2. เขียนเรื่องต่อจากปมด้านบน ใช้คำใหม่ทุกคำ พร้อมพินอิน คำแปล ตัวอย่าง และข้อสอบที่เฉลยถูก
3. สร้าง HTML/Anki แล้วเพิ่มบทใน `build_shared_data.mjs`, หน้า `vocabulary-orbit.html`, ลิงก์บทก่อนหน้า และสารบัญหลัก
4. รันตัวตรวจข้อมูล เปิดในเบราว์เซอร์ ทดสอบคำทั่วไป/คำใหม่ใน reading ปุ่มแสดงพินอิน/คำแปล เสียง ภาพ บัตรคำ เกมวงคำศัพท์ และมือถือ
5. ส่งไฟล์ขึ้น GitHub อัปเดต README และยืนยัน GitHub Pages URL จริง
