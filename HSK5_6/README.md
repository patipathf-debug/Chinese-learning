# HSK5 บทที่ 6 — 照片里的人

## แหล่งคำศัพท์

เปิด [Google Sheet สมุดคำศัพท์จีน](https://docs.google.com/spreadsheets/d/13JLymuUdgZ6lxaDMbHJKK3eEwBGCIS7Kn2QSvkWyeGQ/edit?usp=sharing) วันที่ **10 พฤศจิกายน 2026** และส่งออกเป็น `สมุดคำศัพท์จีน-2026-11-10.xlsx` โดยไม่แก้ชีตต้นฉบับ แท็บ `คลังคำศัพท์` ใช้คอลัมน์ B คำจีน, C หมายเหตุ, D พินอิน, E ความหมาย, F ตัวอย่างจีน บท 5 จบที่แถว 107; บทนี้ใช้แถว **108–125 รวม 18 แถว** แถว 122 `要是VS如果` แยกเป็น **要是** กับ **如果** ซึ่งยังไม่มีในบัตรศัพท์เดิม จึงมี **19 บัตรใหม่** และวงคำศัพท์รวม **122 บัตร** แท็บ `จุดที่ต้องฝึก` มีสูตร `跟/和 + คน + 说 + เรื่อง` ซึ่งใช้สอนในบทนี้

## ไฟล์และวิธีใช้

- `HSK5_6.html`: เรื่องหลินอวี่ต่อจากบท 5 จำนวน 3 ตอนพร้อมภาพ คำจีนใน reading กดดูพินอิน ความหมาย และการใช้ได้ เปิดปิดพินอิน/คำแปลทีละตอน มีตัวเลือกเสียง ศัพท์ใหม่ 19 คำ บัตรคำ และแบบทดสอบ 10 ข้อ
- `anki_hsk5_6.txt`: UTF-8 คั่นด้วย Tab เป็น Front / Back / Tags นำเข้า Anki แบบ HTML เพื่อเก็บรูปแบบพินอิน คำแปล และตัวอย่าง
- `HSK5_6_workbook.pdf`: สมุด A4 **15 หน้า** สำหรับจดบน iPad มีคำศัพท์พร้อมพินอิน/ความหมาย/ทริค เรื่องพร้อมภาพ พื้นที่จด แกรมม่า 3 จุดพร้อมตัวอย่างจุดละ 3 ประโยค และแบบฝึก 10 ข้อพร้อมเฉลย
- `lesson_data.json`: ข้อมูลคำศัพท์ เรื่องอ่าน พินอิน คำแปล และคำถาม
- `images/`: ภาพสีน้ำสามฉากที่สร้างสำหรับบทนี้
- `build_lesson.py`: สร้าง HTML และ Anki จาก JSON โดยใช้หน้า HTML บท 5 เป็นแม่แบบ
- `generate_pinyin.py`: เติมบล็อกพินอินเรื่องอ่านจาก `../reading-lexicon.js` หลังแก้เรื่องหรือพจนานุกรม

## วิธีแก้และสร้างใหม่

1. แก้ `lesson_data.json` และเพิ่มคำทั่วไปที่ยังไม่มีใน `../reading-glossary.json` จากนั้นรัน `node build_shared_data.mjs` ที่โฟลเดอร์หลักจนตัวตรวจยืนยันว่าทุกอักษรจีนใน reading มีคำอ่าน
2. รัน `python3 HSK5_6/generate_pinyin.py` แล้ว `python3 HSK5_6/build_lesson.py` ตรวจพินอิน คำแปล เฉลย และการกดคำบนเว็บ
3. แกรมม่าและโจทย์เขียนอยู่ใน `../pdf_workbook_content.py`; รัน `python3 build_pdf_workbooks.py 6` แล้วเปิดดูหน้า PDF ด้วย `pdftoppm`
4. เมื่อทำบท 7 ให้เปิด Google Sheet ฉบับล่าสุด ใช้เฉพาะแถวหลัง 125 ส่งออกเป็น Excel ใหม่ แล้วอัปเดต `../build_shared_data.mjs`, `../vocabulary-orbit.html`, ลิงก์บทก่อนหน้า, สารบัญ GitHub และ README ตรวจมือถือ ภาพ เสียง ปุ่มซ่อนพินอิน/คำแปล วงคำศัพท์ และ GitHub Pages
