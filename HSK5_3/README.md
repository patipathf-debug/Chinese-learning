# HSK5 บทที่ 3 — 屏幕上的名字

## คำศัพท์ต้นทาง

`สมุดคำศัพท์จีน (2).xlsx` เป็นสมุดสะสม ชีต `คลังคำศัพท์` คอลัมน์ B–D แถว 6–62 มี 57 คำ แถว 6–41 เป็นคำของ HSK5_1 และ HSK5_2 บทนี้ใช้เฉพาะ **21 คำใหม่ในแถว 42–62** ตั้งแต่ `表现` ถึง `既然` ตามลำดับเดิม ช่องพินอินและความหมายของ 21 คำมีอยู่ใน Excel แล้ว; `另外（文法）` และ `而（文法）` ตัดโน้ตวงเล็บออกเพื่อใช้คำจีน `另外` และ `而` ในบทเรียน

ชีต `จุดที่ต้องฝึก` มีแบบฝึกเรียงคำ **和/跟 + คน + 说 + เรื่อง** บทนี้นำไปใช้ในตอนที่ 3 จุดภาษา และข้อสอบ โดยเก็บไฟล์ Excel ต้นฉบับไว้ตามเดิม

## ไฟล์ในบท

- `HSK5_3.html`: เรื่องต่อเนื่อง 3 ตอนพร้อมภาพ คำจีนใน reading ทุกคำกดดูพินอินและความหมายได้ มีปุ่มเปิดปิดพินอิน/คำแปลทั้งตอน คลังศัพท์ 21 คำ บัตรคำ และข้อสอบ 10 ข้อ
- `anki_hsk5_3.txt`: บัตรคำ 21 ใบ แบบ UTF-8 คั่นด้วย Tab; ฟิลด์ Front / Back / Tags นำเข้า Anki แบบ Basic แล้วจับฟิลด์ 3 เป็น Tags
- `lesson_data.json`: ข้อมูลคำศัพท์ เรื่องอ่าน พินอิน คำแปล ภาพ และข้อสอบ เป็นแหล่งเดียวสำหรับการสร้างหน้าและ Anki
- `build_lesson.py`: สร้าง HTML และ TXT จาก JSON โดยใช้บท 5_2 เป็นแม่แบบ รันจากโฟลเดอร์หลักด้วย `python3 HSK5_3/build_lesson.py`
- `images/`: ภาพสามฉากที่สร้างด้วย built-in imagegen สไตล์ภาพสีน้ำต่อจากบท 5_2 และแสดงเต็มสัดส่วนบนมือถือ

ไฟล์ร่วมในโฟลเดอร์หลัก `reading-glossary.json`, `build_shared_data.mjs`, `reading-lexicon.js` และ `reading-interaction.js` ทำให้คำทั่วไปในเรื่องของทั้งสามบทกดได้ทุกคำ ส่วน `vocabulary-data.js` ป้อนข้อมูล 57 คำให้หน้า `vocabulary-orbit.html` ซึ่งกรองตามบท/หมวด ค้นหา ลาก ซูม และแตะดูรายละเอียดได้

## โครงเรื่อง

หลังงานแถลงข่าว บันทึกชี้ว่าหลินอวี่เป็นผู้สร้างบัญชีปลอม เธอกับพี่สาวพบเว็บไซต์รับสมัครงานที่เก็บข้อมูลผู้สมัคร กล่องเอกสารเก่า และภาพของเฉินหนิง อดีตพนักงานที่ยอมเปิดเผยคำสั่งของผู้จัดการ ตอนท้ายกลับพบชื่อหลินเสวี่ยในรายชื่อผู้ใช้ที่ถูกลบ ปมบทถัดไปคือเหตุผลที่พี่สาวถูกลบออกจากข้อมูล

## ขั้นตอนเมื่อเพิ่มบทใหม่

1. เทียบ Excel ใหม่กับคำที่มีอยู่ใน `HSK5_1`, `HSK5_2`, `HSK5_3` นับเฉพาะคำใหม่ ระบุแถวและโน้ตไวยากรณ์
2. เขียนเรื่องต่อจากปมข้างบน ใช้คำใหม่ทุกคำอย่างเป็นธรรมชาติ ทำพินอินและคำแปลตรงกับประโยคจริง พร้อมตัวอย่างและข้อสอบ
3. สร้าง HTML/Anki จาก JSON ของบทใหม่ แล้วเพิ่มบทใน `build_shared_data.mjs` เพื่อให้คำใหม่เข้า `vocabulary-data.js`; เพิ่มคำทั่วไปที่ยังไม่มีใน `reading-glossary.json`
4. รัน `node build_shared_data.mjs` และแก้คำที่รายงานว่าตกหล่นจนผ่าน จากนั้นลองกดคำทั่วไปและคำใหม่ใน reading จริง ตรวจปุ่มซ่อนพินอิน/คำแปล เสียง ภาพ บัตรคำ ข้อสอบ และหน้า orbit บนมือถือ
5. เพิ่มลิงก์บทใหม่ในบทก่อนหน้า หน้า orbit และสารบัญ `index.html` บน GitHub อัปเดต README แล้วตรวจ GitHub Pages URL จริง
