Session 04

写作与 AI 智能批改 — แต่งประโยค & AI ตรวจสอบ

แต่งประโยคภาษาจีนตามโจทย์ที่กำหนด จากนั้นกดให้ Gemini AI ช่วยตรวจไวยากรณ์และแนะนำรูปประโยคที่สละสลวย

🤖 ตั้งค่า Gemini API Key (สำหรับใช้งาน AI ตรวจ)

ใส่ API Key ของคุณที่นี่ ระบบจะบันทึกไว้ในเบราว์เซอร์เครื่องนี้โดยอัตโนมัติ (หากไม่ใส่ API Key ระบบจะแสดงตัวอย่างคำเฉลยและการประเมินแบบออฟไลน์ให้อัตโนมัติ)

โจทย์ที่ 1: แต่งประโยคโดยใช้คำว่า 不断 (อย่างต่อเนื่อง) และ 坚持 (ยืนหยัด)

แนวทาง: บรรยายการฝึกซ้อม หรือการเรียนรู้ภาษาจีนของคุณอย่างไม่ย่อท้อ

โจทย์ที่ 2: แต่งประโยคโดยใช้ไวยากรณ์ 无论……都…… (ไม่ว่าจะ...ก็...) และ 准时 (ตรงเวลา)

แนวทาง: บรรยายเรื่องการเข้าเรียน การส่งงาน หรือการนัดหมายส่งอาหารเดลิเวอรี่
