## วิธีสร้างบทถัดไป

1. สร้างโฟลเดอร์บทใหม่ เช่น `HSK5_2/` และใส่ Excel ของวันนั้นลงไป ตั้งชื่อให้ชัดว่าเป็นบทใด อย่าแก้ข้อมูลต้นทางเพื่อให้เข้ากับเว็บไซต์
2. เปิด Excel แล้วระบุชีตและแถวที่มีคำจริง ตรวจคำจีน พินอิน ความหมาย และคำซ้ำ อย่านับแถวว่างหรือแถวที่มีแต่รูปแบบตาราง
3. สร้างเรื่องต่อเนื่องโดยใช้ตัวละครหลัก **林雨 (หลินอวี่)** ต่อจากบทก่อนหน้า แต่ละบทควรมีเหตุการณ์ใหม่ ปมขัดแย้ง และตอนจบที่ชวนติดตาม ใช้คำใหม่ทุกคำในบริบทที่เป็นธรรมชาติ พร้อมคำแปลไทย
4. ทำ HTML สำหรับบทนั้น โดยมีหัวเรื่อง คำศัพท์ ตัวอย่างประโยค เรื่องอ่าน จุดภาษา เสียงอ่าน บัตรคำ และแบบทดสอบ หน้าเว็บต้องเปิดได้ทั้งจากไฟล์ในเครื่องและจาก URL โดยไม่อ้างถึงไฟล์ที่ไม่ได้ส่งขึ้นเว็บ
5. ทำไฟล์ Anki `.txt` จากคำชุดเดียวกัน: UTF-8, แยก 3 ฟิลด์ด้วยแท็บ คือ **คำจีน / พินอิน+ความหมาย+ตัวอย่าง / แท็กบท** มีส่วนหัว `#separator:tab`, `#html:true`, `#tags column:3` คำหนึ่งใบต่อหนึ่งคำ หากคำซ้ำต่างความหมายให้แยกคำอธิบายให้ชัด
6. ตรวจจำนวนและรายการคำให้ตรงกันระหว่าง Excel, HTML และ Anki ตรวจภาษาจีน พินอิน คำแปล และเฉลยแบบทดสอบ ทดลองค้นคำ พลิกบัตร เล่นเสียง และทำข้อสอบบนจอคอมกับมือถือ
7. ส่งไฟล์บทใหม่และอัปเดตสารบัญในรีโป GitHub `patipathf-debug/Chinese-learning` แล้วตรวจลิงก์จริงบน GitHub Pages ก่อนแจ้งผู้เรียน เก็บบทเก่าไว้เพื่อให้เรื่องอ่านต่อได้
8. อัปเดต README ของบทและ README หลัก: แหล่งข้อมูล จำนวนคำ ชื่อไฟล์ วิธีเปิดเว็บ วิธีนำเข้า Anki และพล็อตที่จะต่อในบทหน้า

## วิธีใช้บท HSK5_1

- เปิด `HSK5_1/HSK5_1.html` ในเบราว์เซอร์ หรือเปิด URL ของบทบน GitHub Pages หลังเผยแพร่
- กดคำสีทองในเรื่องเพื่อฟังเสียง เปิดคำแปลทีละตอน แล้วกลับมาอ่านโดยไม่เปิดคำแปล
- ใน Anki เลือกนำเข้า `anki_hsk5_1.txt` ด้วยตัวคั่น **Tab** และเลือกชนิดโน้ตที่มี Front/Back พร้อมแท็ก ฟิลด์แรกคือ Front ฟิลด์ที่สองคือ Back ฟิลด์ที่สามคือ Tags
- ความคืบหน้าใน HTML อยู่ใน `localStorage` ของเบราว์เซอร์ ไม่ซิงก์ข้ามเครื่อง
