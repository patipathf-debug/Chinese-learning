# HSK5 บทที่ 5 — 消失的那一票

## แหล่งคำศัพท์

`สมุดคำศัพท์จีน (4).xlsx` เป็นสมุดสะสม ชีต `คลังคำศัพท์` คำจีนอยู่คอลัมน์ B, หมายเหตุ C, พินอิน D, ความหมาย E และตัวอย่าง F แถวใหม่ของบทนี้คือ **82–107 รวม 26 แถว** เทียบกับบท 4 ซึ่งจบแถว 81 ก่อนทำบทเรียนแล้ว คำ `以为VS认为` ในแถว 97 แยกเป็น **以为** และ **认为** เพื่อฝึกความหมายต่างกัน ส่วน `既。。又` ในแถว 94 เก็บเป็นโครงสร้าง **既…又** หนึ่งรายการ จึงมีบัตรคำ **27 ใบ** และวงคำศัพท์ห้าบทรวม **103 ใบ** ไฟล์ Excel ต้นฉบับไม่ได้แก้ไข

## ไฟล์และวิธีใช้

- `HSK5_5.html`: อ่านเรื่องหลินอวี่ต่อจากบท 4 สามตอนพร้อมภาพ แตะทุกคำจีนเพื่อดูพินอิน ความหมาย การใช้และเสียง เปิดปิดพินอินหรือคำแปลทั้งตอน รวมศัพท์ 27 คำ บัตรคำ และแบบทดสอบ 10 ข้อ
- `anki_hsk5_5.txt`: UTF-8, คั่นด้วยแท็บ Front / Back / Tags นำเข้า Anki ด้วยตัวคั่น Tab และเปิดการอ่าน HTML ในฟิลด์ Back
- `HSK5_5_workbook.pdf`: A4 จำนวน 17 หน้า เปิดบน iPad เพื่ออ่านและจด มีคำศัพท์ 27 คำพร้อมทริค เรื่องพร้อมภาพ 3 ตอน แกรมม่า 3 จุด (ตัวอย่างจุดละ 3 ประโยค) พื้นที่เขียน แบบฝึก 10 ข้อ และเฉลย
- `lesson_data.json`: ข้อมูลคำศัพท์ เนื้อเรื่อง พินอิน คำแปล และคำถามของบทนี้
- `images/`: ภาพสีน้ำสามฉากที่สร้างให้ตัวละครต่อเนื่องจากบท 4
- `build_lesson.py`: สร้าง HTML/Anki ใหม่จาก JSON ด้วย `python3 HSK5_5/build_lesson.py`

## วิธีแก้และสร้างใหม่

1. แก้ `lesson_data.json` แล้วรัน `python3 HSK5_5/build_lesson.py` ตรวจพินอินและคำแปลที่แสดงในหน้าเว็บ
2. หากเพิ่มคำจีนทั่วไปในเรื่อง ให้เพิ่มคำอ่าน/ความหมายใน `../reading-glossary.json` แล้วรัน `node build_shared_data.mjs` ที่โฟลเดอร์หลักจนตัวตรวจยืนยันครบทุกอักษร ระบบจะสร้าง `reading-lexicon.js` กับ `vocabulary-data.js`
3. แกรมม่าและโจทย์เขียนอยู่ใน `../pdf_workbook_content.py`; หลังแก้ รัน `python3 build_pdf_workbooks.py 5` ที่โฟลเดอร์หลัก แล้วเปิดดูหน้า PDF ด้วย `pdftoppm` ก่อนเผยแพร่
4. เมื่อผู้เรียนขอบท 6 ให้เปิด [Google Sheet สมุดคำศัพท์จีน](https://docs.google.com/spreadsheets/d/13JLymuUdgZ6lxaDMbHJKK3eEwBGCIS7Kn2QSvkWyeGQ/edit?usp=sharing) ใหม่ ส่งออกเป็น Excel ในโฟลเดอร์บท 6 และเริ่มตรวจคำถัดจากแถว 107 (ณ 10 พฤศจิกายน 2026 แถว 108–125 มีคำเพิ่มแล้ว) จากนั้นเพิ่มบทใน `../build_shared_data.mjs`, `../vocabulary-orbit.html`, ลิงก์บนบทนี้, `../index.html` บน GitHub และ README ทั้งสองแห่ง ตรวจมือถือ ภาพ เสียง การกดคำ ปุ่มซ่อนคำแปล/พินอิน และข้อสอบ ก่อนอัปเดต GitHub Pages
