Path 01

เส้นทางเรียนที่ออกแบบให้จำได้นาน

ไม่ต้องเรียนทุกอย่างในครั้งเดียว แนะนำให้เรียนวันละหนึ่งกลุ่มแล้วกลับมาทบทวนแบบไม่เปิดดูคำตอบ

👀

1. สำรวจ

ดูคำจีนและเดาความหมายก่อนเปิดรายละเอียด เพื่อเรียกความรู้เดิมออกมา

🧩

2. เชื่อมโยง

จำผ่านคำที่มักใช้คู่กัน ภาพจำ และข้อควรระวัง ไม่ท่องคำแปลเดี่ยว ๆ

📖

3. อ่านจริง

อ่านเรื่องสั้น 3 ระดับ ใช้วิธีคาดเดา–ชี้จุดติดขัด–สรุปใจความ

🧠

4. เรียกคืน

ปิดพินอินและคำแปล ใช้บัตรคำกับแบบทดสอบ แล้วทวนอีกครั้งใน 1, 3 และ 7 วัน

Section 02

词汇深潜 — เจาะลึกคลังศัพท์

คลิกการ์ดเพื่อเปิดคำอธิบาย คลิกตัวอักษรจีนหรือปุ่มเสียงเพื่อฟังการออกเสียง

Section 03

句型机关 — จุดภาษาที่ต้องรู้

สามจุดนี้เป็นตัวปลดล็อกเรื่องอ่าน และช่วยป้องกันข้อผิดพลาดที่ผู้เรียนไทยมักเจอ

把字句

ประธาน + 把 + กรรม + กริยา + ผลลัพธ์

ใช้เมื่อผู้พูดต้องการเน้นว่า “จัดการกับสิ่งนั้นแล้วเกิดผลอะไร” กริยาจึงไม่ควรยืนเดี่ยว ๆ

✓ 请把门打开。
✗ 请把门开。
打开 แสดงผลว่าเปิดออกแล้ว

从……起

从 + เวลา/จุดเริ่ม + 起

หมายถึง “นับตั้งแต่…เป็นต้นไป” มองไปข้างหน้าจากจุดเริ่ม แตกต่างจาก 从……开始 ที่เน้นการเริ่มทำกิจกรรม

从今天起，我每天复习十分钟。
ตั้งแต่วันนี้เป็นต้นไป ฉันทบทวนวันละ 10 นาที

感动 ≠ 感觉

感动 = ซาบซึ้ง · 感觉 = รู้สึก/ความรู้สึก

感动 เป็นอารมณ์ที่ถูกเหตุการณ์กระทบใจ ส่วน 感觉 เป็นการรับรู้หรือความรู้สึกทั่วไป

这个故事让我很感动。
我感觉有点儿冷。

发生 ≠ 出现

发生 = เหตุการณ์เกิด · 出现 = สิ่งหนึ่งปรากฏ

ใช้ 发生 กับ 事情、问题、变化；ใช้ 出现 เมื่อคน สิ่งของ หรือปรากฏการณ์เผยตัวให้เห็น

昨天发生了一件事。
舞台上出现了一位演员。
