# HSK5 บทที่ 1 — 数字背后的名字

## แหล่งข้อมูล

อ่านจาก `สมุดคำศัพท์จีน.xlsx` ชีต `คลังคำศัพท์` คอลัมน์ B (คำจีน), C (พินอิน), D (ความหมาย) แถว 6–18 รวม **13 คำ** ไม่ใช้ชีต `เพิ่มคำศัพท์` เพราะเป็นหน้ากรอกคำและไม่มีรายการบทเรียน

## ไฟล์บทเรียน

- `HSK5_1.html` เปิดในเบราว์เซอร์ได้โดยตรง มีเรื่องอ่าน 3 ตอนต่อเนื่อง คำศัพท์ 13 คำ จุดภาษา บัตรคำ แบบทดสอบ 8 ข้อ และเสียงอ่านผ่านระบบของเบราว์เซอร์
- `anki_hsk5_1.txt` ใช้ UTF-8 และแท็บคั่น 3 ฟิลด์: หน้าบัตร / หลังบัตร / แท็ก `HSK5_1` นำเข้า Anki แบบ Basic แล้วจับคู่ฟิลด์ที่ 3 เป็น Tags
- HTML ไม่ต้องใช้ไฟล์ JavaScript ภายนอก ข้อมูลความคืบหน้าอยู่ในเบราว์เซอร์เครื่องที่ใช้งาน

## โครงเรื่องสำหรับบทต่อไป

林雨 (หลินอวี่) พบข้อมูลผู้ใช้บางส่วนที่ผิดปกติในแอป “同路” ก่อนงานแถลงข่าว เธอเห็นชื่อพี่สาว 林雪 ในฐานข้อมูล แม้พี่สาวจะออกจากบริษัทไปสามปีแล้ว ตอนท้ายพี่สาวส่งข้อความสารภาพว่าเป็นคนสร้างบัญชีเหล่านั้น บทถัดไปควรเฉลยแรงจูงใจทีละส่วนและพาหลินอวี่ตัดสินใจว่าจะเปิดเผยความจริงอย่างไร

## ขั้นตอนเมื่อมี Excel ของบทใหม่

1. ตรวจชื่อโฟลเดอร์และคำใน Excel ใหม่ นับเฉพาะแถวที่มีคำจริง ตรวจพินอินและคำแปล
2. เขียนตอนต่อจากปมบทนี้โดยใช้คำใหม่ในประโยคที่เป็นธรรมชาติ เพิ่มคำแปลไทยที่ตรงกับภาษาจีน
3. สร้าง HTML และไฟล์ Anki จากรายการคำชุดเดียวกัน แล้วตรวจว่าจำนวนและลำดับคำตรง Excel
4. ตรวจลิงก์ทั้งหมด บัตรคำ เสียงอ่าน ตัวเลือกและเฉลยแบบทดสอบทั้งบนจอใหญ่และมือถือ
5. ส่งบทใหม่ขึ้น GitHub เพิ่มลิงก์สารบัญ และเปิด URL จริงเพื่อตรวจว่าเรียนออนไลน์ได้
