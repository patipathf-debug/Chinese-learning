# HSK5 บทที่ 2 — 两种名单

## แหล่งคำศัพท์

ไฟล์ `สมุดคำศัพท์จีน (1).xlsx` เป็นสมุดสะสม 36 คำในชีต `คลังคำศัพท์` แถว 6–41 เทียบกับ Excel ของ HSK5_1 แล้วแถว 6–18 เป็นคำเดิม 13 คำ บทนี้จึงใช้เฉพาะ **23 คำใหม่** ที่แถว 19–41 เรียงตามต้นฉบับตั้งแต่ `世纪` ถึง `抽烟`

ช่องพินอินและความหมายของคำใหม่ยังว่างใน Excel จึงจัดทำข้อมูลเพิ่มเติมไว้ใน `lesson_data.json` โดยไม่แก้ต้นฉบับ รายการ `按照 ไวยากร` ในแถว 24 ตีความเป็นคำศัพท์ **按照** โดยคำว่า “ไวยากร” เป็นโน้ตภาษาไทย ส่วน `种` ในเรื่องหมายถึง “ชนิด” อ่าน **zhǒng**; หากใช้แปลว่า “ปลูก” จะอ่าน **zhòng**

## ไฟล์ที่ใช้

- `HSK5_2.html` — บทเรียน 3 ตอนต่อจาก HSK5_1, คลังศัพท์ 23 คำ, พินอินและคำแปลเปิดปิดแยกกัน, คำศัพท์ในเรื่องกดดูวิธีใช้, ภาพดูเต็มจอบนมือถือ, เสียงอ่าน, บัตรคำ และแบบทดสอบ 10 ข้อ
- `anki_hsk5_2.txt` — 23 บัตรคำนำเข้า Anki แบบ Tab-separated; ฟิลด์คือ Front, Back, Tags
- `lesson_data.json` — ข้อมูลพินอิน ความหมาย การใช้ ประโยค เรื่องอ่าน และคำถามของบทนี้
- `build_lesson.py` — สร้าง HTML และ TXT จาก JSON โดยใช้ HTML ของ HSK5_1 เป็นแม่แบบ รัน `python3 HSK5_2/build_lesson.py` จากโฟลเดอร์หลักหลังแก้ JSON
- `images/` — ภาพประกอบ 3 ตอนที่สร้างด้วย built-in imagegen สไตล์สีน้ำและตัวละครเดียวกับบทที่ 1

## วิธีเรียน

อ่านเรื่องจีนก่อน แล้วกดคำที่มีเส้นจุดเพื่อดูพินอิน ความหมาย และการใช้ เปิดพินอินทั้งตอนเมื่ออยากตรวจเสียงอ่าน เปิดคำแปลไทยหลังลองตีความด้วยตัวเอง ในคลังศัพท์กดซ่อนพินอินกับคำแปลแยกกัน จากนั้นใช้บัตรคำและแบบทดสอบ

บนมือถือภาพแสดงเต็มสัดส่วน กด **ดูภาพเต็มจอ** ใต้ภาพเพื่อขยายและดูรายละเอียด เสียงอ่านที่เลือกใช้ร่วมกับบทที่ 1 และขึ้นอยู่กับเสียงที่ติดตั้งในอุปกรณ์

## ปมสำหรับบทถัดไป

หลังหลินอวี่กับหลินเสวี่ยเปิดเผยรายชื่อผู้ใช้จริง กลับมีบันทึกใหม่บนจอระบุว่า “ผู้สร้าง: หลินอวี่” ทั้งที่เธอไม่เคยสร้างบัญชีนั้น บทถัดไปควรสืบว่าใครใช้ชื่อเธอและเหตุใด
