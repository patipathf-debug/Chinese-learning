👀

1. สำรวจ

ดูคำจีนและเดาความหมายก่อนเปิดรายละเอียด เพื่อเรียกความรู้เดิมออกมา

📖

3. อ่านจริง

อ่านเรื่องสั้น 3 ระดับ ใช้วิธีคาดเดา–ชี้จุดติดขัด–สรุปใจความ

🧠

4. เรียกคืน

ปิดพินอินและคำแปล ใช้บัตรคำกับแบบทดสอบ แล้วทวนอีกครั้งใน 1, 3 และ 7 วัน

Section 02

คลิกการ์ดเพื่อเปิดคำอธิบาย คลิกตัวอักษรจีนหรือปุ่มเสียงเพื่อฟังการออกเสียง

Section 03

句型机关 — จุดภาษาที่ต้องรู้

สามจุดนี้เป็นตัวปลดล็อกเรื่องอ่าน และช่วยป้องกันข้อผิดพลาดที่ผู้เรียนไทยมักเจอ

本来 ≠ 原来

本来 = เดิมที (แต่เปลี่ยนแล้ว) · 原来 = ที่แท้ / เดิมที

本来 ใช้เมื่อเดิมทีตั้งใจอย่างหนึ่งแต่ตอนนี้เปลี่ยนแล้ว ส่วน 原来 นอกเหนือจากความหมายนี้ยังใช้เมื่อค้นพบความจริงที่เพิ่งรู้ (ที่แท้...)

我本来想去，可是下雨了。
原来是你！我没认出来。
เดิมทีฉันอยากจะไป แต่ฝนตก / ที่แท้ก็เป็นเธอนี่เอง! ฉันจำไม่ได้

将 (jiāng)

将 + คำกริยา (จะ... / กำลังจะ...)

ใช้ในภาษาเขียนเพื่อบอกว่าจะเกิดเหตุการณ์ขึ้นในอนาคต (เหมือน 将要 / 将会) หรือทำหน้าที่นำกรรมมาไว้หน้ากริยาคล้าย 把 ในภาษาพูด

我们将面临很多挑战。
请将这封信交给他。
พวกเราจะเผชิญความท้าทายมากมาย / กรุณานำจดหมายนี้ส่งให้เขา

另 (lìng)

另 + ลักษณนาม [+ คำนาม] (อีก...หนึ่ง)

ใช้ระบุถึงสิ่งอื่นที่แยกต่างหาก มักใช้โครงสร้าง 另一个 (อีกคนหนึ่ง/อีกอันหนึ่ง) หรือ 另外

我想看另一本书。
另一个人还没到。
ฉันอยากดูหนังสืออีกเล่มหนึ่ง / อีกคนหนึ่งยังมาไม่ถึง

理解 ≠ 了解

理解 = เข้าใจลึกซึ้ง (ความรู้สึก/เหตุผล) · 了解 = รู้ข้อมูล/เข้าใจข้อเท็จจริง

ใช้ 理解 เมื่อต้องการสื่อว่าเข้าใจจิตใจ ความรู้สึก หรือความลำบากของอีกฝ่าย; ใช้ 了解 เมื่อรู้ข้อมูล รายละเอียด หรือรู้จักคนคนนั้นดี

我能理解你的心情。
我很了解这个学校。
ฉันเข้าใจความรู้สึกของคุณได้ / ฉันรู้จักโรงเรียนนี้ดีมาก
